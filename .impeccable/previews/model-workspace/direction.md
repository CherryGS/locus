# Model workspace layout specimen

Mode: Operate. Scope: standalone, interactive design specimen with illustrative
data. This is an extension of Locus's incumbent dark visual system. The current
discussion approved the tabbed workspace, common 3:4 cards and local information
editing; spacing and exact placement remain proposals. No production code or
library data is changed.

## Direction contract

THESIS: Make covers useful for scanning a model collection while keeping precise
model information one selection away.

OWN-WORLD: Preserve Locus charcoal surfaces, Geist/CJK sans, muted mint selection,
one-pixel boundaries, compact controls and 4–8px corners. White card text sits on
translucent black. Type and family are small rounded rectangles at the cover's
top left; title and version remain in the bottom overlay.

STORY: Open an independent model tab, scan covers and four identifying fields,
select a model, edit its local version/type/family, and observe source fallback
when a local value is cleared.

FIRST VIEWPORT: Empty workspace with Locus and global feedback. Opening a page
reveals a 40px Locus-and-tabs row above a 40px page-navigation/search row; fixed
240×320 cards fill the remaining canvas with an optional 310px inspector.
Preserve native-control space and the active tab's full close target when many
tabs overflow. Browsing-tab titles stay stable while page history and content
change. Signature interaction: switch independently between an unfiltered model
page and a filtered one, then open/close a task result without losing either.
The retained local-edit demonstration remains available. No entrance animation.

FORM: User-selected grid plus inspector, implemented as a bounded code-led
interactive specimen. No concept seed or image comp was requested for this
continuation. The artifact is a proposal for review, not a finalized visual spec.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Finish scope

Repository rules/implementation.md explicitly excludes extra planning, subagent
review and separate acceptance gates for ordinary UI iteration. Use a bounded
browser inspection and record evidence with the specimen; preserve DESIGN.md.
Rasters are unchanged fixture imagery with recorded origin metadata. Their model
names and classification combinations in the specimen are illustrative.
